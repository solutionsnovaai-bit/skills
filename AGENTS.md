# Instruções para agentes

Ler [CLAUDE.md](CLAUDE.md) para o mapa do acervo e as preferências de Victor. O nome do arquivo é histórico; as instruções de projeto valem também para Codex e outros agentes neste checkout.

Para comandos Higgsfield, consultar [a seleção verificada](referencias/higgsfield-comandos-2026-11.md) e resolver o comando no plugin disponível. Pesquisa e curadoria não autorizam geração. Não consumir créditos Higgsfield com imagens, incluindo intermediárias; vídeo depende de custo informado e alocação autorizada.

Os guias existentes ficam em `.claude/skills/`; os atalhos disponíveis em `.agents/skills/` apontam para essa fonte. Não afirmar que novos comandos ou plugins foram instalados por este catálogo.
