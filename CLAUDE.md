# Repositório de skills

As pastas de `.claude/skills/` são as skills originais dos autores, sem alteração. Siga cada uma como está escrita.

Qual usar:
- Site, landing page, UI: `taste-skill` e `impeccable` para direção e construção; skills do Emil Kowalski (`apple-design`, `emil-design-eng`, `animate`, `choreograph`, `animation-performance`, `review-animations`) para motion e polimento; `web-design-guidelines` para a auditoria técnica antes de entregar; `playwright-cli` para conferir no navegador (celular e desktop).
- Design system de referência: copiar um arquivo de `design-md/` para a raiz do projeto como `DESIGN.md`.
- Vídeo e motion graphics: `hyperframes` (ler primeiro) com `motion-doctrine`, `cut-the-curve`, `seam-craft`, `captions-overlay`, `media-use`, `reverse-any-video` e `hyperframes-registry`; `motionmaxxing` para filmes de motion de nível profissional.

Este repositório é ferramenta interna. Nada daqui (nome do repositório, da agência ou do dono) vai para entregáveis de cliente.
