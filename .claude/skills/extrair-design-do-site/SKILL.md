# Extrair design system do código

1. Identificar o framework, as fontes, os arquivos de tema e os componentes representativos.
2. Ler o [guia original do Google Labs](guia-google.md) e somente a referência do framework em uso. Os arquivos originais estão preservados junto com sua licença.
3. Registrar valores observados de cor, tipografia, espaçamento, superfícies e componentes. Separar observações do código e decisões propostas para o redesign.
4. Aplicar o método ao projeto atual. Usar o caminho de documentação já adotado pelo projeto, ou `DESIGN.md` quando a entrega pedir esse documento. O caminho específico de Stitch do guia só é necessário quando esse fluxo estiver em uso.
5. Verificar amostras de componentes e a correspondência entre o documento e os estilos reais. Resolver tokens e aliases antes de registrar os valores finais.

**Incluído.** Guia integral, cinco referências de frameworks e exemplo de DESIGN.md.
